How this demo works & how to connect real data

What you're looking at right now

This screener runs entirely in your browser, with no server and no internet calls. The gauge, sentiment split, trend chart and mention feed are all generated sample data, seeded from your keywords, platforms and date range so the same inputs always produce the same demo results. It's here so you can shape the exact inputs, layout and metrics you want before wiring in a real data source.

Why a local HTML file can't scrape live platforms

Browsers block a page from one site (a local file, in this case) from silently fetching content off another site's servers, and none of Facebook, Instagram, TikTok or X serve their content to anonymous scripts anyway — most of it sits behind a login and gets rendered by JavaScript on their end. Pulling it programmatically without permission also runs against those platforms' terms of service. So this needs to change at the data layer, not the UI — the screener above is designed so the front end doesn't need to change when you do.

Three real paths, in order of how easy they are to stand up

Free & sanctionedOfficial APIs, where they exist. The YouTube Data API is free and gives you real comment/video search by keyword — the most realistic first step. X (Twitter) has a paid API tier (starts around $100/mo) for search access. Facebook and Instagram's Graph API mainly exposes content you or your Page/Business account own, not public search across the platform. TikTok has no public search API.

  • Needs: API keys (free for YouTube) and a small backend or serverless function to call them from — keys can't safely live in a plain HTML file.

Paid, does this exactlyA licensed social listening vendor (e.g. Brandwatch, Meltwater, Talkwalker, Sprout Social, Mentionlytics). These companies have data-licensing deals with the platforms specifically to do cross-platform keyword/hashtag listening, sentiment and trend scoring — it's their whole product. Most offer an API or CSV export you could pipe straight into a dashboard shaped like this one.

  • Needs: a subscription, no scraping involved, fastest path to genuinely reliable cross-platform data.

Do-it-yourself, fragile & riskyA custom backend that fetches public pages directly. Technically possible for a narrow slice of always-public content (e.g. public YouTube pages, some public X posts), but it's fragile (breaks whenever the platform changes its markup), typically requires headless-browser automation to render JavaScript, and for Instagram/Facebook/TikTok/X in particular tends to violate their terms of service — which risks IP/account blocks and, depending on how it's used, legal exposure. Not recommended as your primary path.
